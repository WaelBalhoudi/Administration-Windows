# Windows Server Administration Labs

This repository contains the practical labs and documentation completed during my first year of the Master's degree at ISET Sfax.

## Topics Covered

- Active Directory Domain Services (AD DS)
- DNS & DHCP
- Group Policy Objects (GPO)
- IIS Web Server
- FTP Server
- File Services
- Windows Deployment Services (WDS)
- Windows Server Update Services (WSUS)
- Network Policy Server (NPS), RADIUS & VPN
- Active Directory Trust Relationships
- Failover Clustering

## Environment

- Windows Server 2022
- Hyper-V / VMware
- Windows 10 Client

## Skills

- Domain Administration
- User & Group Management
- Network Services Configuration
- Authentication & Authorization
- Server Deployment
- High Availability
